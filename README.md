## <img src="https://img.shields.io/badge/-%E2%9A%A1-1a1b26?style=flat-square" height="22"/> &nbsp;About Me

```yaml
engineer:
  name: Arham Apon Utsho
  studying: B.Sc. Software Engineering @ Islamic University of Technology (2027)
  builds:
    - distributed backends that stay consistent under concurrency
    - LLM pipelines with multi-provider fallbacks and defensive parsing
    - interpretable ML on large tabular data
  philosophy: "Correctness first, then speed — and make failure modes boring."
```

I engineer systems where the hard part is invisible: idempotent consumers that refuse to double-spend, AST-level code analysis that pinpoints bugs from a plain-English issue, and background pipelines that keep the UI instant. I care about architecture that survives real load, and AI that is grounded rather than guessed.
